# Variant 3 — "Kiln" · Tactile Depth / Vibrant

**Concept.** A departure from the app's dark glass bento grid into a warm, physical world:
glazed ceramic tiles laid on a sunrise-lit sand table. Every widget is a pressed-clay
tile with dual-tone soft shadows (warm shadow below-right, cool highlight above-left) so
the surface reads as something you could actually push. Data isn't decoration painted on
glass — it's *molded* into the material.

**Palette (hex).**
- Sand table: `#F5E9D2` → `#EFDDBE` (warm radial sunrise glow `#FBDFA9` top-left)
- Tile glaze: `#FDF6E8` → `#F2E2C6`
- Espresso ink (text): `#3A2A1C`, muted `#9C8464`
- Terracotta (primary / revenue): `#E1552F`
- Marigold (gold tier / accent): `#F5A623` and `#F7C948`
- Coral (device / warmth): `#F26D5B`
- Teal glaze (cool balance / silver): `#159A8B`
- Plum (premium / platinum): `#6E3A6F`

**Type.** Display + hero numbers: **Bricolage Grotesque** (800), chunky and a little
wonky — feels hand-formed, not corporate. Body/labels: **Manrope** (rounded humanist).
Data ticks: **Space Mono** for a tactile, tabular readout. Same families the design system
ships, deployed in an opposite key (light, warm) so it's clearly a fresh direction.

**Layout.** An asymmetric "workbench": a hero band of 4 color-coded ceramic KPI chips, a
full-width revenue relief tile as the anchor, then a staggered bento of tier / category /
device / channel tiles. Saturated color is a real coding system — each membership tier,
device and category owns a fixed hue everywhere it appears.

**Aesthetic risk.** Light claymorphism with an *extruded 3D revenue ridge* — the hero
chart is a molded clay hill (layered fill + soft drop shadow + a lit top rim) and every
tile physically depresses on press. Claymorphism is risky (reads toy-ish, low-contrast if
done lazily), so it's disciplined with strong espresso ink for AA contrast and one signature
moment instead of glow everywhere. It's justified: the brief asked for tactile, delightful-
to-touch depth — the opposite of a flat corporate dashboard.
